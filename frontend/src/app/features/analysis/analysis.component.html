Metric comparison across splits

The ROC curve plots True Positive Rate vs False Positive Rate at every threshold. A model that perfectly separates classes has AUC = 1.0. AUC > 0.90 is excellent for anomaly detection.

The Precision-Recall curve is more informative than ROC on imbalanced datasets. Average Precision (AP) summarises the curve as a single number. AP = 1.0 is perfect.
